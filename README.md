# カスタムラベルスタジオ (Custom Label Studio)

美容サロン（美容室・ヘアサロン・エステ・ネイルサロン等）向けの店販商品ラベル・プライスカード・施術回数券・優待チケット作成＆高精度印刷Webアプリケーションです。

---

## 🌟 主な特徴

- 🖨️ **エーワン (A-one) 品番 51467 に完全最適化**
  - 公式仕様書（4列×11連 44面 / 48.3×25.4mm）に基づき、上余白8.8mm、左余白8.4mm、列間・段間0mmの連続ミシン目チケットにミリ単位で完全適合。
  - 名刺サイズ（10面カード 91×55mm）のレイアウトにもワンクリックで切り替え可能。
- 🖱️ **直感的なマウス操作（ドラッグ移動 ＆ 縦横オートフィル）**
  - **場所移動・入れ替え**: 枠をつかんでドラッグ＆ドロップするだけで、空き枠への移動や既存枠同士の入れ替え（スワップ）が可能。
  - **オートフィル（連続コピー）**: 枠の右下の青いポッチをドラッグすると、真下（縦）または右隣（横）へ1枠ずつ安全・直感的に連続コピー。
- 📋 **スマートな作成履歴 ＆ モーダル選択（完全重複排除）**
  - シリーズ名・商品名・サイズ/価格・色が同じラベルは重複せず1つだけ保持。
  - 「履歴から選ぶ（大きく表示）」ボタンで、実寸比率の大きなチケットカードから一覧選択可能。
  - 選択するとモーダルが自動で閉じ、左上の入力欄に一瞬で自動入力（ピカッと点滅アニメーション付き）。
  - ブラウザの `localStorage` に自動保存されるため、次回作業時も履歴を保持。
- ⚡ **サーバー不要・完全オフライン動作**
  - フロントエンド単一ファイル（HTML5 / Tailwind CSS / Vanilla JS）で完結。
  - 面倒な環境構築不要で、ブラウザで開くだけですぐに使用可能。
- 🎯 **A4実寸ミリ単位の高精度印刷**
  - CSS `@page { size: A4 portrait; margin: 0; }` により、ブラウザ印刷時の余白ズレを排除。45面以上は自動で2ページ目へ改ページ。

---

## 🚀 使い方

1. `index.html` をお好みのブラウザ（Google Chrome, Microsoft Edge など）で開きます。
2. 左上のフォームから「シリーズ名」「商品名」「容量・価格・条件」「カラー」を入力します。
3. 「シートに追加する」を押すと、A4プレビューの空き枠に自動配置されます。
4. シート上の枠をクリックすると直接編集モードになり、右下の青いポッチをドラッグすると真下や右隣へ連続コピーできます。
5. 「履歴から選ぶ」ボタンを押すと、過去に作成したユニークなラベルが大きく表示され、ワンクリックで左上に入力できます。
6. 右上の「A4用紙に印刷する」ボタン（または <kbd>Ctrl</kbd> + <kbd>P</kbd>）を押して印刷します。
   - ※印刷設定で「余白: なし（または最小）」「背景のグラフィック: オン」に設定してください。

## ⌨️ キーボードショートカット

| ショートカット | 機能 |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | 選択中の枠をコピー |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | 選択中の枠（または先頭の空き枠）へ貼り付け |
| <kbd>Ctrl</kbd> + <kbd>D</kbd> | 選択中の枠を次の空き枠へ複製 |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 選択中の枠を削除（白紙化） |
| <kbd>Ctrl</kbd> + <kbd>P</kbd> | A4印刷ダイアログを開く |
| <kbd>Esc</kbd> | 履歴モーダルを閉じる / 選択解除 |
